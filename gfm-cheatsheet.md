# GFM Cheatsheet
A markdown cheatsheet with Github-Flavoring added.

## Alert Syntax

```markdown
> [!<alert>]
> Alert text here
> Alert can continue on multiple lines
>
> Alert can have paragraph breaks
```

Alerts:

* NOTE
* TIP
* IMPORTANT
* WARNING
* CAUTION

> [!NOTE]
> This is a note.
>
> Any of these alerts can have multiple paragraphs, just use a double-spaced
> line break.
> But a single-spaced line break, like this, just sends a line break, like this.

> [!TIP]
> Here's a helpful tip: You can make tips.

> [!IMPORTANT]
> The space between `>` and `[` is critical.

> [!WARNING]
> Warning shows with a yellow /!\ sign icon. It means watch out. Think of this
> as error level WARNING.

> [!CAUTION]
> Like warning, but with a red stop sign (!) icon. Think of this as error level
> ERROR.
